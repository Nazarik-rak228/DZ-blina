Предметная область: Система управления учебными курсами. Сущности: User, Role, Course, Schedule. Связи реализованы через внешние ключи (роль привязана к пользователю, преподаватель к курсу и расписанию).
Структура папок:
bin/l14bd.dart
lib/CLI/menu.dart
lib/Data/database.dart, coursesRepo.dart, roleRepo.dart, shesuleRepo.dart, user-repo.dart
lib/domain/id.dart, user.dart, role.dart, course.dart, shedule.dart
lib/validation/valid.dart
test/l14bd_test.dart, valid.dart
Что вынесено в каждый слой и почему:
domain - модели данных. Изолированы от БД и интерфейса, чтобы бизнес-объекты можно было менять независимо от хранения.
Data - работа с SQLite и CRUD-операции. Вынесено, чтобы в меню не было SQL-запросов и логики подключения.
validation - функции проверки ввода. Вынесено для переиспользования и чтобы не засорять код меню условиями.
CLI/menu.dart - вывод пунктов и обработка выбора. Отвечает только за консольный интерфейс.
Какие валидации реализованы:

    Обязательное текстовое поле (проверка на null и пустоту после trim) - функция requareParametr
    Формат даты (корректный парсинг строки в DateTime) - функция checkDate
    Формат email (проверка наличия @ и .) - функция checkEmail

Перечень тестов:
Файл: test/valid.dart
Тесты requareParametr: валидная строка с пробелами, строка из пробелов, null.
Тесты checkEmail: корректный адрес, строка без @, строка без точки.
Тесты checkDate: корректный формат YYYY-MM-DD, битая строка, пустое значение.
